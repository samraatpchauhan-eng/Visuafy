**7/24/2026**
 - This is probably the greatest start to any hardware project I have ever had! I was able to spend a good hour and a half planning out VisuaFy, deciding which hardware components to use, and even built the Main housing that all the components will sit in! I decided to use an 8x8 led matrix display, and a Raspberry Pi Pico 2020 rp2040, as they are cheap and widely availible. Since I use spotify the most, I decided to make it visualize songs from that platform!

 Hardware Components (For the display I decided not to use a 1000uF capacitor as I plan to cap the brightness at about 70% as this led matrix can get extremely bright)
